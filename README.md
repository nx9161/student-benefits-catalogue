# Student Benefits Catalogue — US Edition

246 verified student benefits, deals, and freebies — one searchable catalogue for students in the US.

**Live site:** [student-benefits-catalogue.vercel.app](https://student-benefits-catalogue.vercel.app)

## About

A curated, verified catalogue of student discounts, free software, and benefits — every entry checked, no dead links. Built for students who'd rather not pay full price for anything.

## Features

- Searchable, categorized catalogue of 246 verified benefits
- Every link verified working
- 69 launch destinations for quick access

## Tech Stack

- Single-file static HTML/CSS/JavaScript — no build step, no dependencies

## Updating the Site

The site ships as one `index.html`. To update: edit the source, save as lowercase `index.html`, and deploy.
